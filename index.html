    Sugerencias

    Cada sugerencia aparece en el plan cuando se cumple su condición. Podés cambiar nombre, prioridad y condición acá; las soluciones, motivos y preguntas se editan en el JSON de abajo.

    Cómo se escriben las condiciones
    • Datos de la receta: add, lejos (tiene graduación de lejos), miopia, hipermetropia, astigmatismo, potencia, anisometropia, receta (cargada), receta_meses, receta_tipo, edad.
    • Respuestas: el código de cada pregunta, por ejemplo maneja == "noche", "pc" in trabajo, pantallas in ["5-8","8+"].
    • Unir: and / y, or / o, not / no, paréntesis. Comparar: == != > >= < <=.
    • Ejemplo: add > 0 and (lejos or "lejos" in dist)
